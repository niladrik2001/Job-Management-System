This job portal application enables users to create profiles, post jobs, browse available opportunities, and track application statuses. Built using React Router for navigation and React Query for efficient data fetching and caching, it integrates Cloudinary for resume/image uploads and Mongoose for structured MongoDB schema design. The backend APIs, developed with Express.js and Node.js, handle authentication, user roles, job CRUD operations, and secure file uploads. Axios is used for client-server communication, ensuring a smooth, responsive experience.

The platform supports features like role-based access, search and filter options, and a user-friendly interface designed to streamline job hunting and recruitment processes.
